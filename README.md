# LeetCode Solutions

This repository contains LeetCode solutions written in Java and MySQL.

## Structure

- `Java/submissions/` contains Java solutions, organized by problem.
- `MySQL/submissions/` contains MySQL solutions for database problems, organized by problem.

Each problem folder contains the problem statement and its solution files.

## Problem Folder Naming

Problem folders follow this format:

```text
<problem-number>-<problem-name>/
```

Example:

```text
Java/submissions/1-two-sum/
```

## Solutions

- Java solution files include the problem solution and, where available, submission results such as runtime and memory usage.
- MySQL solution files use MySQL syntax and match the requirements of each LeetCode database problem.
